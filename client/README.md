# E-Commerce Client

This is the frontend for the MERN E-Commerce platform, featuring a modern, SaaS-style user interface built with Tailwind CSS.

## Tech Stack

*   **Framework:** React 18
*   **Routing:** React Router v6
*   **Styling:** Tailwind CSS
*   **Authentication:** Firebase
*   **HTTP Client:** Axios

## Getting Started

1.  Make sure you have installed the dependencies:
    ```bash
    npm install
    ```

2.  Start the development server:
    ```bash
    npm start
    ```
    This will run the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

For full project documentation (including backend setup), please see the [root README](../README.md).
